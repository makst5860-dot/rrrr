# 🥖 Тістоміс-радар

Шукає вживані тістоміси **Kemper** і **Diosna** до **1500 €** і надсилає сповіщення на iPhone — лише про **нові** оголошення.

```
GitHub Actions (≈48 разів на добу, нерівні проміжки 12–46 хв)
   └─ scanner/ → Kleinanzeigen 🇩🇪 · willhaben 🇦🇹 · Marktplaats 🇳🇱 · 2dehands 🇧🇪
                 Subito 🇮🇹 · Wallapop 🇪🇸 · Bazoš 🇸🇰 🇨🇿 🇵🇱 🇦🇹
        ├─ відсіює: гітарні Kemper Profiler, вентилі Kemper, кемпери, «куплю/suche», запчастини
        ├─ ціна 300–1500 € і НЕ договірна (VB, Verhandlungsbasis, trattabile, dohodou…)
        ├─ мало переглядів (≤ 10) або, якщо лічильника немає, оголошення не старше 3 днів
        ├─ нове? → сповіщення в застосунок ntfy на iPhone (з фото і кнопкою «Відкрити оголошення»)
        └─ журнал: data/listings.json
```

Робот працює на серверах GitHub цілодобово — телефон може бути вимкнений.

## Налаштування (один раз)

1. **Зробити репозиторій приватним:** Settings → General → внизу *Danger Zone* → **Change visibility** → **Make private**.
2. **iPhone:** встанови безкоштовний застосунок **ntfy** з App Store → **+** → *Topic name*: назва теми (надіслана окремо, починається з `tistomis-`) → **Subscribe** → дозволь сповіщення.
3. **GitHub:** Settings → **Secrets and variables → Actions → New repository secret**
   - Name: `NTFY_TOPIC`
   - Secret: та сама назва теми.
4. **Перевірка:** вкладка **Actions** → *Пошук тістомісів* → **Run workflow** → галочка *Надіслати тестове сповіщення* → **Run workflow**. За хвилину на iPhone прийде «✅ Тістоміс-радар працює».

Назву теми тримай у секреті — хто її знає, може читати ці сповіщення.

### Озвучка
iPhone → **Параметри → Сповіщення → Оголошувати сповіщення** → увімкнути й вибрати **ntfy**. Siri зачитуватиме нові оголошення в AirPods і в CarPlay.

### Щоб не пропустити
Параметри → Сповіщення → ntfy → **Дозволити сповіщення**, звуки, банери «Постійно». Якщо користуєшся режимами фокусування — додай ntfy до дозволених.

## Змінити пошук

Усе в `config.json`:
- `maxPriceEur` / `minPriceEur` — межі ціни;
- `allowNegotiable` — дозволити договірну ціну (VB тощо);
- `maxViews` / `maxAgeDaysIfNoViews` — «свіжість» оголошення;
- `sources.*.enabled` / `queries` — сайти і пошукові запити;
- `excludeWords` / `mixerWords` — що відсіювати і що вважати тістомісом;
- `includeNoPrice` — сповіщати й про оголошення без ціни.

Вимкнені, бо блокують запити із серверів GitHub (HTTP 403): OLX (PL, RO, PT, BG), eBay.de, leboncoin.fr, tutti.ch.

Розклад — `.github/workflows/scan.yml`. Приватний репозиторій на безкоштовному GitHub має 2000 хв Actions на місяць; одна перевірка ≈ 1 хв, тож ~48 на добу вкладаються в ліміт. Частіше — лише з платним планом.

## Перевірка вручну

**Actions → Пошук тістомісів → Run workflow → Детальний лог** — покаже, що знайдено на кожному сайті і чому оголошення відсіяно (без сповіщень і збереження).

Локально: `npm install && npm test && npm run scan`.

# 🥖 Тістоміс-радар

Шукає вживані тістоміси **Kemper** і **Diosna** до **1500 €** і надсилає сповіщення на iPhone — лише про **нові** оголошення. Можна вмикати озвучку.

**Застосунок:** https://makst5860-dot.github.io/rrrr/

## Як це працює

```
GitHub Actions (кожні ~10–15 хв, у випадковий час)
   └─ scanner/  → Kleinanzeigen 🇩🇪 · willhaben 🇦🇹 · Marktplaats 🇳🇱 · 2dehands 🇧🇪 · OLX 🇵🇱 · eBay 🇩🇪
        ├─ відсіює гітарні Kemper Profiler, вентилі Kemper, «куплю», запчастини
        ├─ ціна ≤ 1500 € (злоті перераховує в євро)
        ├─ нове? → push-сповіщення на iPhone (+ ntfy, якщо налаштовано)
        └─ зберігає список у docs/data → його показує застосунок
docs/  → застосунок (PWA): встановлюється на iPhone з Safari, показує оголошення, озвучує нові
```

Робот працює на серверах GitHub цілодобово і безкоштовно — телефон може бути вимкнений.

## Налаштування (один раз, ~5 хв)

1. **Увімкнути сайт:** GitHub → репозиторій `rrrr` → **Settings → Pages** → *Build and deployment*: Source **Deploy from a branch**, гілка — та, що за замовчуванням, папка **/docs** → Save.
2. **Секрет із ключем:** **Settings → Secrets and variables → Actions → New repository secret**
   - Name: `VAPID_PRIVATE_KEY`
   - Secret: приватний ключ (надісланий окремо, у репозиторії його немає).
3. **Встановити на iPhone:** відкрий https://makst5860-dot.github.io/rrrr/ у **Safari** → **Поділитися** → **На початковий екран**.
4. Відкрий «Тістоміси» з іконки → **Увімкнути сповіщення** → **Дозволити** → **Скопіювати код**.
5. GitHub → **New repository secret** → Name: `PUSH_SUBSCRIPTIONS`, Secret: встав скопійований код.
   Кілька телефонів: `[код1, код2]`.
6. Перевірка: **Actions → Пошук тістомісів → Run workflow** → постав галочку *Надіслати тестове сповіщення* → Run.

### Озвучка
- **Коли застосунок відкритий:** кнопка «Озвучка» вгорі — нові оголошення зачитуються вголос українською.
- **У фоні:** iPhone → Параметри → Сповіщення → **Оголошувати сповіщення** → увімкнути для «Тістоміси». Siri читатиме сповіщення в AirPods і CarPlay.
- Якщо голос не український: Параметри → Універсальний доступ → Усний контент → Голоси → Українська.

### Запасний канал (необовʼязково): ntfy
Встанови застосунок **ntfy** з App Store, підпишись на вигадану назву (напр. `tistomis-7f3k9q`) і додай секрет `NTFY_TOPIC` з цією назвою.

## Змінити пошук

Усе в `config.json`:
- `maxPriceEur` — ліміт ціни;
- `sources.*.enabled` / `queries` — сайти і пошукові запити (є вимкнений OLX.ua);
- `excludeWords` / `mixerWords` — що відсіювати і що вважати тістомісом;
- `includeNoPrice` — показувати оголошення без ціни.

Розклад — `.github/workflows/scan.yml` (`cron` + випадкова пауза до 4 хв).

## Перевірка вручну

**Actions → Пошук тістомісів → Run workflow → Детальний лог** — покаже, що знайдено на кожному сайті і чому оголошення відсіяно (без сповіщень і без збереження).

Локально: `npm install && npm test && npm run scan`.
